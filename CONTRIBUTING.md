# Contributing to Nobash Backup

Thank you for your interest in improving Nobash Backup.

1. Search the existing issues before opening a new one.
2. For a bug, include reproducible steps, expected/actual behavior, relevant WordPress and PHP versions, and logs with secrets removed.
3. Keep pull requests focused and explain tests performed. Do not mix cosmetic and unrelated functional changes.
4. Test backup, verification, and restore operations in a disposable WordPress environment. Never use a production website as a first test.
5. Do not upload private backup archives, customer information, credentials or access tokens.

There is no guaranteed response time for contributions or issues.
